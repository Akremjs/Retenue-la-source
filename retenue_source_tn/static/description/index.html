Retenue à la source (Tunisie)

Clients & fournisseurs

Module Odoo pour gérer la retenue à la source (RAS) conforme à la réglementation tunisienne : calcul, écriture comptable, lettrage, seuil, types d'opération TEJ.

Fonctionnalités

  • Bouton Retenue à la source sur facture client / fournisseur
  • Base hors timbre fiscal
  • Écriture dédiée + réconciliation automatique
  • Documents RAS (brouillon / comptabilisé / annulé)
  • Seuil configurable (défaut 1000 TND)
  • Types d'opération TEJ + taxes RAS
  • Contrôles matricule / exonération partenaire

Démonstration

1. Bouton sur facture

2. Assistant de création

3. Document RAS

4. Écriture comptable

5. Configuration journal

6. Configuration taxe

Configuration rapide

  1. Journal : activer RAS Clients ou RAS Fournisseurs + compte par défaut
  2. Taxe : cocher Taxe RAS (vente / achat) + type d'opération TEJ
  3. Facture comptabilisée non payée (> seuil) → bouton Retenue à la source
