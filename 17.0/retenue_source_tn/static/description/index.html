Retenue à la source (Tunisie)

Clients & fournisseurs

Module Odoo pour gérer la retenue à la source (RAS) : calcul, écriture comptable, lettrage, seuil et types d'opération TEJ.

Fonctionnalités

  • Bouton Retenue à la source sur facture client / fournisseur
  • Base hors timbre fiscal
  • Écriture dédiée + réconciliation
  • Documents RAS (brouillon / comptabilisé / annulé)
  • Seuil configurable + types TEJ + contrôles matricule

Démonstration

1. Bouton sur la facture

Depuis une facture publiée, lancez la RAS en un clic.

2. Assistant de création

Choisissez le journal, la taxe RAS et validez le montant retenu.

3. Liste des documents RAS

Suivi des retenues clients / fournisseurs (référence, base, montant, statut).

4. Configuration journal

5. Configuration taxe

Configuration rapide

  1. Journal : activer RAS Clients ou RAS Fournisseurs + compte par défaut
  2. Taxe : cocher Taxe RAS (vente / achat) + type d'opération TEJ
  3. Facture publiée non payée (> seuil) → bouton Retenue à la source
